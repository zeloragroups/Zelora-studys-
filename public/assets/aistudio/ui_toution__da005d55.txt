SCHOLARS ACADEMY — COMPLETE PREMIUM UI/UX TRANSFORMATION

Project: $10 Million-Class Product Design | Full Application Redesign

PRIMARY OBJECTIVE

Transform the existing Scholars Academy Tuition Centre Management Ecosystem into an exceptionally polished, premium, professional education management platform.

The quality target is comparable to a product designed and developed by a highly experienced international product-design agency.

This must not look like:

- A generic AI-generated dashboard.
- A basic tuition management template.
- A collection of unrelated cards.
- A typical admin panel with default components.
- A cheap mobile application with inconsistent icons.
- A website template with only different colours.

It must feel like a carefully designed, commercially valuable software product.

Use the supplied visual reference as the foundation:

- Premium fintech-inspired visual language.
- Clean white surfaces.
- Deep charcoal sections.
- Fresh mint-green accents.
- Beautifully balanced spacing.
- Refined typography.
- Sophisticated card layouts.
- High-quality navigation.
- Elegant transitions and interactions.

Adapt this visual language to an education management ecosystem. Do not copy financial application content or financial application layouts blindly.

The result should be recognizably Scholars Academy, with a distinctive and consistent visual identity.

3. COLOUR SYSTEM — 60/30/10 RULE

Use the 60-30-10 colour principle.

The palette must be consistent across all application screens.

Light theme

Primary 60% — Main surfaces

- Background: #F7F9F8
- Main content surface: #FFFFFF
- Secondary surface: #F0F4F2

Use these for the main application background, page surfaces and large content areas.

Secondary 30% — Charcoal

- Primary charcoal: #20262B
- Deep charcoal: #171D21
- Secondary charcoal: #343C42

Use charcoal for strong headings, navigation elements, selected dark surfaces and visual contrast.

Accent 10% — Mint green

- Primary mint: #35D6A0
- Deep mint: #18B985
- Soft mint: #DDF8EE
- Mint border: #B8EBD8

Use mint green for primary actions, selected states, progress indicators and important positive highlights.

Do not colour every icon, heading or card green.

Mint must remain an accent, not the entire interface.

Supporting colours

Use restrained semantic colours:

- Success: #168A63
- Warning: #D69B35
- Error: #D64C55
- Information: #4285A5
- Neutral text: #68737C

Ensure text contrast meets WCAG AA wherever practical.

Do not use colour as the only method of communicating status.

Dark theme

Create a separately tuned dark theme using the same visual identity.

- Main background: #151A1E
- Main surface: #1D2429
- Secondary surface: #252E33
- Elevated surface: #2B353A
- Primary text: #F4F7F6
- Secondary text: #AAB6B4
- Primary mint: #42DDA9
- Soft mint: #244B3E
- Border: #344047

Dark mode must feel intentionally designed.

Do not simply invert the light theme.

Preserve readable contrast, subtle surface differences and carefully controlled highlights.

Theme requirements

- Retain the existing Light/Dark theme switch.
- Retain existing theme persistence.
- Ensure every module uses the same design tokens.
- Avoid hardcoded colours scattered across components.
- Do not introduce purple as the main accent.
- Do not introduce unnecessary gradients.
- Do not use bright green everywhere.
- Do not use excessive glassmorphism.
