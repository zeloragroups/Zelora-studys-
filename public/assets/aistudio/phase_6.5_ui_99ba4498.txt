4. VISUAL DESIGN DIRECTION

4.1 Overall design concept

Create a premium, advanced, modern education-management interface.

Use visual inspiration from high-quality fintech applications, premium productivity software and modern education dashboards.

However, do not copy another product's interface.

The result must feel original and specifically designed for a tuition management system.

The desired visual character:

- Premium.
- Clean.
- Modern.
- Confident.
- Professional.
- Minimal but informative.
- Advanced without unnecessary complexity.
- Easy for students, teachers and Admin to understand.

Avoid:

- Generic AI-generated dashboard appearance.
- Excessive gradients.
- Too many floating cards.
- Excessive rounded containers.
- Oversized headings.
- Random decorative elements.
- Unnecessary glass effects.
- Excessive shadows.
- Inconsistent icon styles.
- Overly bright colors.
- Unnecessary animations.
- Repeated identical dashboard layouts for every role.

The design should look professionally crafted, not automatically generated.

4.2 Primary visual palette

Use a refined dark navy and electric-purple visual identity.

Suggested starting palette:

These are starting design tokens, not permission to apply colors blindly.

Evaluate the palette across real screens and adjust it for readability, hierarchy and contrast.

Use a consistent 60-30-10 color distribution:

- 60% dominant background and surface colors.
- 30% secondary surfaces and supporting colors.
- 10% accent and emphasis colors.

Do not make every card purple.

Purple should be used selectively for active navigation, important actions, selected states and meaningful highlights.

5. ADVANCED BOTTOM NAVIGATION — MOST IMPORTANT REQUIREMENT

Create a premium bottom navigation system for the mobile and tablet experiences.

This is a major visual feature of Phase 6.5.

Every role must have a clearly visible Home button positioned exactly in the middle of its bottom navigation.

This applies separately to:

1. Admin.
2. Teacher.
3. Student.

Do not put Home at the left or right.

Do not use a separate floating Home button that is disconnected from the navigation bar.

The Home button must be the central item in the bottom navigation itself.

5.1 Navigation structure

Use five navigation positions.

The Home item must always occupy position three.

<escape>
[ Item 1 ]   [ Item 2 ]   [ HOME ]   [ Item 4 ]   [ Item 5 ]
</escape>Maintain balanced spacing on both sides.

Use appropriate destinations for each role.

Admin bottom navigation

Recommended structure:

1. Overview.
2. Academics.
3. Home.
4. Assessments.
5. Profile.

Admin must still be able to access other existing management modules, such as Accounts, Attendance, Announcements and other existing sections, through a well-organized secondary navigation or appropriate navigation drawer.

Do not remove access to any existing Admin feature merely to fit five items.

Teacher bottom navigation

Recommended structure:

1. Classes.
2. Attendance.
3. Home.
4. Homework.
5. Profile.

Teacher must retain access to existing:

- Objective tests.
- Examinations.
- Marks entry.
- Results.
- Timetable.
- Announcements.
- Other existing authorized modules.

Use a well-organized More menu, secondary navigation or appropriate module navigation to expose these features.

Do not hide or remove functionality.

Student bottom navigation

Recommended structure:

1. Learning.
2. Attendance.
3. Home.
4. Tests.
5. Profile.

Students must retain access to existing:

- Homework.
- Test results.
- Examination results.
- Subject performance.
- Timetable.
- Announcements.
- Notifications.
- Other existing student features.

Use secondary navigation or a well-organized More menu where required.

5.2 Centre Home button design

The Home button must be slightly more noticeable than the other navigation items.

Create a subtle elevated centre-button treatment:

- Slightly larger icon.
- Slightly elevated position.
- Distinct circular or softly rounded background.
- Refined purple accent.
- Subtle glow in dark mode.
- Subtle shadow or elevation in light mode.
- Clear Home label.
- Smooth active-state animation.
- Balanced size so it does not dominate the entire navigation bar.

It must feel premium, not exaggerated.

Do not use a huge floating action button.

Do not make it cover the content.

The central Home button should be immediately recognizable as the main navigation destination.

5.3 Bottom navigation appearance

Design the navigation bar with:

- A clean, refined surface.
- Subtle top border or shadow.
- Appropriate rounded corners where suitable.
- Equal spacing.
- Consistent icon sizes.
- Clear labels.
- Proper active-state indicators.
- Smooth transitions.
- Adequate touch targets.
- Safe-area padding for modern phones.

In dark mode, use a deep navy navigation surface.

In light mode, use a clean white or soft neutral surface.

The navigation must remain readable and attractive in both themes.

5.4 Navigation interactions

Implement:

- Animated active icon.
- Subtle active-item indicator.
- Smooth route transitions.
- Correct navigation state after browser back/forward.
- Correct selected item for nested routes.
- Home always returns to the correct role-specific dashboard.
- No navigation to another role's dashboard.
- No broken links.
- No duplicate navigation actions.

The bottom navigation must not reset a user's authentication session.

5.5 Bottom navigation responsive behavior

Mobile:

- Fixed to the bottom.
- Five navigation positions.
- Home in the exact centre.
- Proper safe-area spacing.
- No content hidden behind the navigation bar.

Tablet:

- Use a suitable responsive bottom navigation where it improves usability.
- Preserve the same central Home principle when using bottom navigation.

Desktop and laptop:

- Preserve a professional desktop navigation system, normally the existing sidebar or an improved equivalent.
- Keep Home prominently available in the primary navigation.
- Do not force a mobile bottom navigation onto a large desktop screen if it harms usability.
- Maintain consistent navigation names and destinations across screen sizes.
