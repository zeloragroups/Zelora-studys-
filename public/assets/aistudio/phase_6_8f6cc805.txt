12. AUTOMATIC OBJECTIVE-TEST EVALUATION

Implement deterministic evaluation logic in the service layer.

No AI is needed.

For each submitted attempt:

- Compare each selected answer with the correct answer.
- Award configured marks for a correct answer.
- Award zero for an incorrect answer.
- Award zero for an unanswered question.
- Calculate total marks obtained.
- Calculate percentage.
- Preserve the submitted answers.
- Preserve the evaluation result.

Formula:

Percentage = (Marks Obtained / Total Marks) × 100

Reject tests with zero total marks.

The student interface must not calculate or overwrite official results.

The service layer must be responsible for evaluation.

Result visibility

Support these result-release options:

- Release automatically after submission.
- Release manually by the assigned teacher.
- Keep results hidden until a configured release time.

Before release, students may see a submission confirmation but must not see correct answers or marks.

After release, show:

- Marks obtained.
- Maximum marks.
- Percentage.
- Correct answers, if the teacher enables this.
- Explanations, if available.
- Submission date.
- Attempt number.

Do not reveal private answer keys before results are released.
